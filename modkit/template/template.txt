# Cluster display entry the Android Auto hook offers the phone, applied to
# Update/gal_cluster.so by build_sd_package.sh (modkit/template/
# cluster_template_tool.py). One key=value per line, frame pixels at
# codecRes=1080 (1920x1080); '#' starts a comment. Keys not listed keep the
# tool's defaults. Remove this file to ship the hook as released.
#
# The entry declares no margins: the phone lays its cluster UI out over the
# whole 1920x1080 frame, of which the cockpit shows rows 179..900 with
# gal_h264.panY=0 (centred crop), and the content insets keep the car marker,
# the turn card and the arrival line inside the part between the dials. The
# values are those of the cluster entry in the upstream release v1181, tried
# on an A6 C8 (P2711) with Google Maps on 18 November 2026: arrow in the
# centre, turn card at the top, arrival line at the bottom, all of it clear of
# the dials in the large map view and in the view with the two large dials,
# parked and driving. Android Auto gets the entry once per connection, so one
# entry has to serve both cockpit views.
#
# Tried before and dropped:
# - Q7 values from PR #11 (margins top 179 / bottom 180, height_margin 358,
#   insets bottom 195 / left 160 / right 160): the turn card sits behind the
#   speed dial (also reported on an e-tron).
# - the same margins with insets left 500 / right 624 at density 160 (beta 3):
#   the card is visible in both views, but flush right next to the dial.
# - the v1181 values as margins instead of insets: the large view is almost
#   black. Margins 179/180 with insets 680/680 at density 145: no turn card.
